# 📊 ขบวนการเอเจนต์ประจำปุ่ม "สถิติ" (Stats Tool)

← กลับไป [[01 - Shared Agents (Memory & Router)]] · ตอนถัดไป → [[03 - Knowledge Tool Agent]] · ไปดูเส้นทางเวิร์กโฟลว์: [[02 - Statistics Workflow]]

> ภายใต้ปุ่มโหมดสถิตินี้ จะมีแก๊งเอเจนต์ซ่อนตัวแบ่งกะทำงานอยู่ 3 ทีมใหญ่: **(A) ทีมสิงห์ SQL อุบัติเหตุ** (2 ตัว), **(B) ทีมวิเคราะห์ CSV หน้าเดียว** (6 ตัว), และ
> **(C) ทีมยำตาราง Multi-CSV ข้ามโดเมน** (3 ตัว)

## A. ทีมสิงห์อุบัติเหตุ — พำนักที่ไฟล์ `accident_chat_orchestrator.py` (รุม 2-agent)

### A1. นักเลงข้อมูลอุบัติเหตุ (Accident SQL Data Specialist)
- **ระดับสมองโมเดล:** สายไว fast (ใช้ flash, ค่า temp 0.1) · **คิดซ้ำสุด:** 4 รอบ · **อาวุธ tools:** พกคลังแสง `ACCIDENT_CHAT_TOOLS` (มีดาบ SQL tools ให้เลือกดึงกว่า 15+ แบบ ที่เก็บจาก `accident_chat_sql.py`)
- **เป้าหมาย (goal):** *"งัดเอาความจริง ดึงข้อมูลอุบัติเหตุทางถนนที่ถูกต้องเป๊ะๆ และครบถ้วนมาจากฐานข้อมูล โดยรู้จักเลือกใช้เครื่องมือ tool ได้อย่างเฉียบขาด"*
- **ปูมหลัง (backstory):** *"คุณคือปรมาจารย์ด้านฐานข้อมูลอุบัติเหตุทางถนน หลับตาเดินก็รู้จักซอกหลืบตาราง mart/fact/dim ทั้งหมดเป็นอย่างดี รวมถึงรู้ซึ้งถึงข้อจำกัดช่องโหว่ของเดต้า"*
- **ความสามารถล้นเหลือ:** สั่งรันเรียก SQL tools (ไม่ว่าจะเป็นหาจุดเสี่ยง hotspot/ดูพฤติกรรม/ดักฤดูกาล/ตามตัวชี้วัด KPI) โดยการคิวรีล้วงลึกผ่านตาราง `mart_province_road`, `mart_province_year`, `mart_accident_hotspot`, และโหนด `dim_geography`

### A2. มือเขียนรายงานนโยบาย RTI (RTI Policy Answer Writer)
- **ระดับสมองโมเดล:** **สายลึก pro** (ใช้ gemini-2.5-pro, ค่า temp 0.2 ให้มีศิลปะนิดๆ) · **คิดซ้ำสุด:** 5 รอบ · **อาวุธ tools:** — (ไม่มี เป็นมือเปล่าสายบุ๋น)
- **เป้าหมาย (goal):** *"ชุบชีวิตตัวเลขแห้งๆ ให้กลายเป็นคำตอบภาษาไทยทางการที่ชัดเจนสละสลวย เสิร์ฟตาราง Markdown สวยๆ พร้อมตีพิมพ์ข้อเสนอแนะเชิงนโยบาย เพื่อส่งขึ้นโต๊ะผู้บริหาร สสจ./ศปถ./สสส."*
- **ปูมหลัง (backstory):** *"คุณคือนักยุทธศาสตร์การสื่อสารนโยบายความปลอดภัยทางถนน กฎเหล็กของคุณคือ จะเขียนรายงานเฉพาะสิ่งที่ตัวเลขเดต้ามีหลักฐานรองรับ **ห้ามมโนสร้างตัวเลขเสกขึ้นมาเองเด็ดขาด**"*
- **ความสามารถล้นเหลือ:** ย่อยผลสถิติดิบ → กลั่นเป็นรายงานภาษาไทยทางการ + วาดตารางประกอบ + พร้อมห้อยเชิงอรรถเตือนสติเรื่องข้อจำกัดข้อมูลเสมอ (มาตรการ anti-hallucination ป้องกันการมั่ว)

## B. ทีมเจาะตาราง CSV หน้าเดียว — พำนักที่ `csv_pipeline.py` (ส่งไม้ต่อ 6-agent)

> ลำดับการวิ่งผลัด: นักท่องโฟลเดอร์ (Folder Navigator) → นักถอดโครง (Schema) → มือปั้นโค้ด (Code Gen) → ห้องประหารรันโค้ด (Executor) → ปิดท้ายที่นักวิเคราะห์ (Insight)
> (หมายเหตุ: ถ้าดันเลือกโดเมน `d0` สายถามปัญหาสุขภาพทั่วไป จะลัดคิวให้ **หมอที่ปรึกษา (Health Advisor)** มารับจบตอบตรงไปเลย)

### B0. หมอที่ปรึกษา Health Advisor (รับแขกเฉพาะ d0 ทั่วไป)
- **เป้าหมาย (goal):** *"ไขข้อข้องใจปัญหาสุขภาพ เป็นภาษาไทยที่ดูโปร เป็นทางการ สุภาพ ชัดเจน ถูกหลักวิชาการแพทย์เป๊ะ และนำไปใช้ประโยชน์ได้จริง"*
- **ปูมหลัง (backstory):** คุณคือหมอสาธารณสุขผู้เชี่ยวชาญ คล่องแคล่วในการพูดจาภาษาทางการ เหมาะกับสไตล์งานราชการ/วิชาการจ๋าๆ; และเป็นนักจำสามารถจำบทสนทนาต่อเรื่องเก่าได้
- **อาวุธ tools:** — · เน้นตอบตรงประเด็นกระชับเหมือนกำลังนั่งโต๊ะให้คำปรึกษาคนไข้ (และจะคอยอ้างอิงเนื้อหาจากตู้ Vault context ถ้ามีแนบมาให้)

### B1. นักเดินป่าหาหมวดหมู่ Folder Navigator Agent — {ของโดเมนนั้นๆ}
- **คิดซ้ำสุด:** 3 รอบ · **อาวุธ tools:** — (ไม่มี ใช้ตาอ่านกางแผนที่ "folder tree" ที่เรายัดแนบไปใน prompt เอา)
- **เป้าหมาย (goal):** *"สแกนดูแผนผังหมวดหมู่ป่าข้อมูล (folder tree) อย่างรวดเร็ว แล้วจิ้มเลือก 'ชื่อโฟลเดอร์ตัวชี้วัด' ที่เข้าเป้ากับหัวข้อคำถามของผู้ใช้มากที่สุด หยิบมาห้ามเกิน 3 รายการนะ"*
- **ปูมหลัง (backstory):** คุณอิงความรู้จาก `domain.expertise` + กฎเหล็ก *"จงจำไว้ว่า 'ชื่อโฟลเดอร์' (ไม่ใช่ชื่อไฟล์ที่โดนย่อจนกุด) คือตัวบอกใบ้ว่าข้อมูลในนั้นกำลังชี้วัดเรื่องอะไร ... อนุญาตให้เลือกจิ้มได้เฉพาะชื่อโฟลเดอร์ที่มีปรากฏอยู่ใน tree เท่านั้น ห้ามมโนชื่อขึ้นมาเองเด็ดขาด"*
- **ความสามารถล้นเหลือ:** หน้าที่มันคือดึง "ความหมาย" (ดึงชื่อโฟลเดอร์) ออกมา — จากนั้นระบบหลังบ้านจะเอาชื่อนั้นไปเทียบหา (resolve) รหัส file ID ให้เอง (นี่คือหลักการสุดล้ำที่ว่า *ให้ AI รับจบเรื่องความหมาย แล้วให้สคริปต์โค้ดไปงมหาไฟล์ต่อ*)

### B2. นักถอดสคีมา Schema Analyst Agent — {ของโดเมนนั้นๆ}
- **อาวุธ tools:** แบกเครื่องอ่าน `[read_csv_schema]` · **คิดซ้ำสุด:** 5 รอบ
- **เป้าหมาย (goal):** ชำแหละดูตารางโครงสร้าง (schema) ของชุดข้อมูลที่ได้มาจาก `file_id`
- **ปูมหลัง (backstory):** อิงความรู้ `domain.expertise` + บังคับให้ควักเครื่องมือ `read_csv_schema` ยิงใส่ `file_id` ที่ได้รับมอบหมายมาเท่านั้น
- **ความสามารถล้นเหลือ:** จะพ่นบทสรุปว่ามีคอลัมน์อะไรบ้าง/เป็นเดต้าชนิดไหน/ขอดูแถวตัวอย่างหน่อย (ถ้าเอเจนต์ตัวนี้ดันเอ๋อ ระบบจะมีท่าไม้ตายสำรอง (fallback) แอบไปแอบเรียกโค้ด `read_csv_schema_impl` ตรงๆ มายัดให้แทน)

### B3. มือปืนปั้นโค้ด Python Code Generator — {ของโดเมนนั้นๆ}
- **อาวุธ tools:** — (พิมพ์สด) · **คิดซ้ำสุด:** 5 รอบ
- **เป้าหมาย (goal):** *"ตั้งสติอ่านคำถามให้แตกระฉานซะก่อน จากนั้นกระหน่ำพิมพ์โค้ด Python/Pandas ที่ทำหน้าที่ขุดค้ยหาเดต้าให้ตอบโจทย์สิ่งที่เขาถาม โค้ดที่พิมพ์มาต้องเอาไปรันได้เลยทันทีไม่ต้องซ่อม และต้องพรินต์ผลลัพธ์ออกมาให้ดูง่าย"*
- **ปูมหลัง (backstory):** โดนสะกดจิตด้วยคาถา `join_prompt(domain.expertise, "คุณคือเซียน Python/Pandas expert ที่รู้ลึกถึงบริบท...", CODE_GENERATOR_CORE_POLICY)`
- **ความสามารถล้นเหลือ:** เสกโค้ด pandas ล้วนๆ (มีจุดย้ำว่าผลลัพธ์ที่จะสั่ง print ต้องมีเลเบล/ชื่อจริงกำกับด้วย เพื่อให้ไอ้ตัว Insight ลำดับถัดไปอ่านแล้วรู้เรื่อง)

### B4. ห้องประหารรันโค้ด Python Executor (ขั้นตอนนี้ใช้สคริปต์โค้ดล้วน ไม่เพิ่งพา LLM)
- จะจับเอาโค้ดที่ไอ้ตัว B3 เขียนมา ไปโยนใส่ฟังก์ชัน `tools/minio.py execute_python_code` เพื่อกดรัน (ทำงานในโลกมืด subprocess แยกต่างหาก, มีไลบรารี pandas/numpy/scipy สแตนด์บายให้พร้อม)

### B5. นักวิเคราะห์สาธารณสุขอาวุโส Senior Public Health Data Analyst — {ของโดเมนนั้นๆ} (ตัวสรุป Insight)
- **อาวุธ tools:** — · **คิดซ้ำสุด:** 5 รอบ
- **เป้าหมาย (goal):** *"ทำความเข้าใจสิ่งที่ผู้ใช้ถาม แล้วจับเอาตัวเลขมาร้อยเรียงเขียนเป็นรายงานระดับทางการสำหรับส่งให้ผู้บริหารระดับสูง สสจ. อ่านรายงานนี้จบปุ๊ปต้องฟันธงตัดสินใจเชิงนโยบายได้ทันที"*
- **ปูมหลัง (backstory):** โดนสะกดจิตด้วย `join_prompt(expertise, "คุณคือนักวิเคราะห์ระดับอาวุโส ... กฎการพูดคือให้เปิดประเด็นพุ่งเป้าไปที่สิ่งที่ค้นพบเลย ห้ามเกริ่นคำแก้ตัวน้ำท่วมทุ่ง ... และจงหยิบใช้เฉพาะตัวเลขเดต้าที่ออกมาจากผลลัพธ์ Execution Result เท่านั้น", ANALYST_CORE_POLICY)`
- **ความสามารถล้นเหลือ:** ฉลาดเลือกโครงสร้างรายงานตามรูปคดีคำถาม (เขียนเชิงภาพรวม/เจาะรายอำเภอ/กราฟแนวโน้ม/หรือเจาะพื้นที่สีแดงเสี่ยง) + โชว์เหนือด้วยการขีดเขียนตาราง Markdown

## C. ทีมยำใหญ่ Multi-CSV ข้ามแดน — พำนักที่ `multi_csv_pipeline.py` (ส่งไม้ต่อ 3-agent)

### C1. นักเดินป่าข้ามโดเมน Multi-Domain Folder Navigator Agent
- **คิดซ้ำสุด:** 5 รอบ · **อาวุธ tools:** —
- **เป้าหมาย (goal):** *"...สแกนหา 'ชื่อโฟลเดอร์ตัวชี้วัด' ที่ตรงปกกับหัวข้อมากที่สุด เลือกมาได้ลิมิตไม่เกิน 5 รายการ แต่ต้องใจกว้างครอบคลุมกวาดให้ครบทุก domain ที่เกี่ยวข้อง"*
- **ปูมหลัง (backstory):** คุณคือผู้เชี่ยวชาญระดับหัวกะทิในการจัดหมวดหมู่ข้อมูลสาธารณสุข (รู้ลึกถึงขั้นที่ว่า ถ้าพูดถึงโฟลเดอร์ "ร้อยละผู้ป่วยเบาหวาน...DM remission" มันอยู่ตรงไหน)
- **ความสามารถล้นเหลือ:** ขยี้ประโยคคำถามแตกเป็นประเด็นย่อย → แล้วไปไล่ช็อปปิ้งหยิบโฟลเดอร์มา ≤ 5 โฟลเดอร์ให้ครอบทุกหมวด (แล้วสคริปต์โค้ดจะไปแปลงชื่อเป็น id ไฟล์ให้เอง)

### C2. มือปั้นโค้ดรวมร่าง Multi-DataFrame Python Code Generator
- **คิดซ้ำสุด:** 5 รอบ · **อาวุธ tools:** —
- **เป้าหมาย (goal):** *"รัวคีย์บอร์ดสร้างโค้ด Python/Pandas มหัศจรรย์ ที่ทำหน้าที่หลอมรวม (merge) ตาราง DataFrame หลายแผ่นเข้าด้วยกัน แล้วสั่งพรินต์ผลงานออกมาให้ประจักษ์ โดยผลลัพธ์ต้องทำตามกรอบ Target Spec มีชื่อพื้นที่จริงประกอบครบ และตัวเลขต้องสอบทานได้"*
- **ปูมหลัง (backstory):** รับคาถา `join_prompt("เซียน Python/Pandas expert ... อนุญาตให้งัดสูตรสำเร็จ pct_rank()/composite_score() ที่เตรียมไว้ให้มาใช้ได้ ... กฎคือชื่อจังหวัดห้ามแหว่ง ตัวเลขต้องมีป้ายเลเบลแปะเสมอ", CODE_GENERATOR_CORE_POLICY)`
- **ความสามารถล้นเหลือ:** ท่าไม้ตายคือการเขียนโค้ด join ตารางข้าม dataset หน้าตาเฉย (โดยมีสคริปต์สุนัขดมกลิ่น Geo-Key Detector คอยกระซิบบอก key ที่ใช้เชื่อมให้)

### C3. นักวิเคราะห์ตาเหยี่ยวข้ามโดเมน Cross-Domain Insight Analyst
- **คิดซ้ำสุด:** 5 รอบ · **อาวุธ tools:** —
- **เป้าหมาย (goal):** *"จงเพ่งมองวิเคราะห์แก่นแท้ของผลลัพธ์ตัวเลขจริง ที่ยำมาจากข้อมูลหลายโดเมน แล้วนำมาเรียงร้อยถักทอเป็นรายงานระดับทางการสำหรับส่งผู้บริหาร สสจ."*
- **ปูมหลัง (backstory):** รับคาถา `join_prompt("นักวิเคราะห์ระดับโครตเซียนประจำเขต ... บรรทัดแรกเริ่มด้วยสิ่งที่ค้นพบเลย ... ห้ามมโนตัวเลขหรือเมคชื่อสถานที่สมมติขึ้นมาเองเด็ดขาด ใช้ของที่มีจาก Execution Result เท่านั้น", ANALYST_CORE_POLICY)`
- **ความสามารถล้นเหลือ:** มองหาแพทเทิร์นลวดลาย/หาจุดเชื่อมโยงจับคู่ความสัมพันธ์ของสถิติข้ามโดเมนได้อย่างเฉียบขาด

## 📜 ภาคผนวก: รวมฮิตคัมภีร์กฎเหล็กพรอมต์ส่วนกลาง (Core Policy)
- แก๊งกฎเหล็ก `CODE_GENERATOR_CORE_POLICY` / `ANALYST_CORE_POLICY` / และ `MISSING_DATA_POLICY` ถูกนำเข้าเก็บตัวมาจากตู้ `prompt_profile.py`
  — ทำหน้าที่เหมือนยาปฏิชีวนะ คอยฉีดกฎ **"จงเสพข้อมูลจริงเท่านั้น / ถ้าต้องเดาให้ระบุชัดเจนว่าเป็นค่าประมาณการ / และกฎประหารคือห้ามแต่งตัวเลขเองเด็ดขาด"** เข้าเส้นเลือดใหญ่ของเอเจนต์สายวิเคราะห์ทุกตัวก่อนปล่อยไปทำงาน
